## FH6HUD
基于CLI的极限竞速：地平线6外置HUD，解决内置HUD看上去不够有张力的问题，建议配合Immersive Camera Enhanced使用（https://www.nexusmods.com/forzahorizon6/mods/417）

可能会有bug，我遇到的都修好了，但是也没有彻底测试过

## 功能
输入监视：油门刹车开度，转向输入角度

车辆数据监视：挡位，速度，转速，G力，车轮打滑

车辆动态响应：
- 速度：面板抖动/缩放
- 加速度：面板缩放，垂直/水平偏移
- 角速度：水平旋转，垂直旋转

转速计数据：
- 前x%马力/最大马力/换挡RPM
- 引擎功率曲线校准

## 使用
1. 下载Release中的二进制文件或者下载.NET10 SDK然后运行BUILD.bat
2. 启动游戏和ForzaHud.exe
3. **在游戏设置中打开数据遥测**，程序默认读取127.0.0.1:2247
4. 检查视觉效果是否符合你的喜好

功率曲线校准：
- 使用气缸数量，性能等级，最大转速，传动系统类型还有车辆ID确认身份，只有所有都符合的个体才会被算作同一辆车
- 数据默认储存在forzahud-calibration.json
- 每检测到一辆未记录的车都会触发自动校准，过程中红色的RPM CALIBRATION指示会被显示
- **如果牵引力控制没有关闭，则需要配置牵引力控制检测**，默认通过读取游戏画面来判断TCR是否激活，需要在游戏设置内使用默认HUD安全区和**数字车速表**（只推荐使用默认的Frame模式，Telemetry模式不准）
- 校准过程中，需要正常驾驶一段时间，默认要求以>=99%油门输入覆盖最少50%的转速区域，受TCR影响的样本会被丢弃，所以建议使用不触发TCR的较高档位
- 如果已经获得足够数据，进入暂停菜单会结束校准过程，如果暂停+恢复后RPM CALIBRATION指示没有消失，一般代表转速覆盖不足
- ``CTRL+ALT+K``可以删除当前车辆的记录，重启校准
- 对于无法校准或者不需要的车，按``CTRL+ALT+P``为当前车辆禁用该功能

## 配置
默认配置文件：hud.json

如果要调节动态响应，找``visual.panelMotion``

颜色 - ``visual.theme visual.opacity``

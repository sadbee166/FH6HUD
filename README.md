## FH6HUD
极限竞速：地平线6的外置HUD

## 功能
输入监视：油门刹车开度，转向输入角度

车辆数据监视：挡位，速度，转速，G力，车轮打滑

车辆动态响应：
- 速度：面板抖动/缩放
- 加速度：面板缩放，垂直/水平偏移
- 角速度：水平旋转，垂直旋转

转速计监视：
- x%马力/最大马力/换挡点
- 自动功率曲线校准

## 使用
1. 下载Release中的二进制文件或者下载.NET10 SDK然后运行BUILD.bat
2. 启动游戏和ForzaHud.exe
3. 检查视觉效果是否符合你的喜好
功率曲线校准：
- 使用气缸数量，性能等级，最大转速，传动系统类型还有车辆ID确认身份，只有所有都符合的个体才会被算作同一辆车
- 数据默认储存在forzahud-calibration.json
- 每检测到一辆新车都会触发自动校准，红色的RPM CALIBRATION指示会被显示
- 校准时如果牵引力控制没有关闭，则需要配置牵引力控制检测，默认通过读取游戏画面来判断TCR是否激活，建议在游戏设置内使用默认HUD安全区和数字车速表（只推荐使用默认的Frame模式，Telemetry模式还不准）
- 校准过程中，需要正常驾驶一段时间，默认要求以最大油门输入尽可能覆盖更多转速区域，所以建议使用不打滑的较高档位
- 如果已经获得足够数据，进入暂停菜单会结束校准过程，如果暂停+恢复后RPM CALIBRATION指示没有消失，一般代表转速覆盖不足
- CTRL+ALT+K可以删除当前车辆的记录，重启校准过程
## 配置
默认配置文件：hud.json

如果要调节动态响应，找visual.panelMotion

颜色 - visual.theme, visual.opacity
